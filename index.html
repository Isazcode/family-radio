Program your radio

  1. Install CHIRP (free) on a Windows, Mac or Linux computer. Get the "CHIRP-next" build.
  2. Download the file for your radio and area below.
  3. Plug the radio in with its programming cable and turn it on. In CHIRP: Radio → Download from Radio, then File → Save As to keep a backup.
  4. On the Memories tab, press Ctrl+A then Delete to clear the old channels.
  5. File → Import, pick the file, then Radio → Upload to Radio.
